# ReMon
Private copy of the GHUMVEE SVN repository

Even though this repo is called ReMon, I _STRONGLY_ recommend that you clone it into a folder called MVEE in your home directory. A lot of my scripts will break if you don't.

To clone, use:
```
cd ~
git clone git@github.com:securesystemslab/ReMon.git MVEE
```
